## Overview

Personal developer portfolio showcasing selected software projects, technical skills, and links to the broader project and learning ecosystem.

The portfolio is intentionally lightweight and uses vanilla HTML, CSS, and JavaScript so it can be hosted as a static site without a build step.

## Featured Work

- **AutiSmart** — AI-assisted healthcare/FYP platform for autism-related screening, tracking, and support workflows.
- **ClinicOS** — Clinic management platform with therapist, session, and treatment-plan workflows.
- **SchoolIEP** — Educational IEP platform for student goals and progress management.
- **EduConnect** — Educational forum and counseling platform.
- **University Course Projects** — Collection of systems, networking, database, compiler, and other academic projects.

## Run Locally

1. Clone or download the repository.
2. Open `index.html` in a browser.

No build tools or package installation are required for the portfolio frontend.

## Portfolio Principles

- Keep project descriptions concise and proof-backed.
- Link directly to the relevant GitHub repositories.
- Prefer meaningful projects over a long list of small demos.
- Keep public profile information consistent across the portfolio ecosystem.
