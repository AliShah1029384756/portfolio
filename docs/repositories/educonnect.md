# EduConnect

## Role

Earlier education-support full-stack project and an important predecessor in the user's education-domain product work.

## Purpose

EduConnect was designed to unify student discussion, counseling, learning resources, profiles, and progress context in one role-aware platform.

## Core Features

- Authentication/access control
- Forum/community threads
- Counseling requests
- Resource discovery/bookmarking
- Progress tracking/analytics
- Profile management
- Admin monitoring

## Technology

- Node.js
- Express.js
- MongoDB/Mongoose
- HTML/CSS/JavaScript frontend
- JWT/bcrypt authentication
- Security middleware including Helmet/rate limiting and request sanitization
- Nodemailer/multer utilities

## Architecture

Modular Express application using route boundaries, controllers, middleware, utilities, public frontend assets, and configuration/DB connectivity.

## Relationship to Later Projects

EduConnect is an **earlier education-support project**, not the same product as EduCore, SchoolIEP, or AutiSmart.

It is useful as evidence of the evolution of the user's thinking around education workflows:

`EduConnect → education-support workflows → SchoolIEP / broader learning products`

The final profile should avoid implying that these projects are one codebase unless that is actually true.
