# ClinicOS

## Role

Healthcare/clinic management project focused on organizing clinic and therapy workflows.

## Purpose

ClinicOS represents a domain-focused management system for therapists/clinics, including session and treatment-plan workflows.

## Key Areas

- Therapist-oriented workflow
- Session management
- Treatment-plan management
- Clinic operational data
- Healthcare-oriented product workflow

## Technical Position

Full-stack web application work with emphasis on practical CRUD/workflow architecture and healthcare-domain modeling.

## Relationship to AutiSmart

ClinicOS and AutiSmart share the broader healthcare/therapy domain, so concepts such as sessions, treatment planning, progress, and user roles can be conceptually related. They should still be presented as separate products with separate scopes.

## Portfolio Position

**High.** Useful as a supporting healthcare full-stack project alongside AutiSmart.
