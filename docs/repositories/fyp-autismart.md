# Fyp-Autismart

## Role

Primary public-facing Final Year Project repository for **AutiSmart**, a hybrid web-based application focused on autism-spectrum support workflows.

## Purpose

AutiSmart is designed to support parents, caregivers, therapists, and related users through screening-stage classification, symptom tracking, therapy support, progress monitoring, awareness material, and AI-assisted interaction.

## Major Modules

- ASD stage detector / screening workflow
- Symptom tracking
- Therapy recommender
- Parent and expert portal concepts
- Progress dashboard
- Urdu/English awareness material
- AI chat assistant
- Text/audio/video analysis concepts
- Data export
- Therapy games for initial/middle stages

## Technology

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MongoDB
- Architecture: MVC-style backend
- AI: multimodal/agentic AI concepts
