# Web Development Learning Track

## Role

Structured, project-driven curriculum for becoming a reliable full-stack developer through disciplined engineering execution.

## Purpose

Turn scattered web-development learning into a progression covering implementation, APIs, data modeling, architecture, testing, security, deployment, open source, and career packaging.

## Curriculum Modules

1. Frontend Engineering
2. Backend Engineering
3. Databases and Data Modeling
4. System Design and Architecture
5. Testing and Quality
6. DevOps and Deployment
7. Security and API Hardening
8. Open Source Playbook
9. Career, Portfolio and CV

## Audience Modes

- **Student Mode:** sequential self-study + capstone
- **Junior Developer Mode:** use modules as a project audit checklist
- **Mentor Mode:** reuse modules for guided cohorts and assignments

## Execution Model

```text
Build Feature
   ↓
Design API + Data Model
   ↓
Add Tests + Validation
   ↓
Harden Security
   ↓
Document + Package
   ↓
Create Portfolio Case Study
```

## Key Files

- `WEEKLY_PLAN.md` — execution rhythm
- `01_Frontend_Engineering/` through `09_Career_Portfolio_and_CV/` — curriculum
- `resources/awesome-links.md` — curated references

## Relationship to Web Dev Learning Hub

These two repositories are related but serve different purposes:

- **`web-dev-learning-hub`** → public-facing learning hub/curriculum presentation and discovery experience
- **`web-dev-learning-track`** → deeper structured engineering curriculum and execution framework

The track is therefore better treated as the **curriculum/knowledge source**, while the hub can serve as the **student-facing presentation/discovery layer**.

## Relationship to Portfolio

The track explicitly includes portfolio packaging and links to a web-track case-study page. It can therefore support future professional branding, but it should not be mistaken for the final personal portfolio itself.
