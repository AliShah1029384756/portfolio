# SchoolIEP

## Role

Education-focused project for Individualized Education Program (IEP) workflows.

## Purpose

SchoolIEP focuses on organizing student goals, educational planning, and progress-related information in a structured digital workflow.

## Domain

Education + student support + progress management.
