# EduCore Open Learning Hub

## Role

General/public open-learning platform. It is intentionally separate from the FAST-specific resource hub.

## Purpose

EduCore organizes free educational material into a searchable, student-friendly discovery experience for a broad audience.

## Audience

- School and college students
- University learners
- Entry-test learners
- CS/SE/IT students
- Urdu/English learners
- Learners seeking structured learning paths

## Main Features

- Resource search and filters
- Subject/category browsing
- Learning paths
- Bookmarks
- Continue-learning history
- Local progress tracking
- Urdu/English metadata
- Responsive/accessibility-focused interface
- Contribution workflow
- Curated JSON-based dataset

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- JSON data
- Browser localStorage
- Font Awesome
- GitHub Pages

## Architecture

Static frontend + curated data files + browser-local personalization. No mandatory account/backend is required for core discovery.
