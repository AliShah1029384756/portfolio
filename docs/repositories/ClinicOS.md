# ClinicOS

## Role

Full-stack healthcare-style workflow application demonstrating React/Node.js architecture, REST APIs, MongoDB data modelling, JWT authentication, RBAC, and operational dashboards.

## Purpose

Organize therapy operations around patients, therapy sessions, treatment plans, therapist workflows, and progress tracking.

## Technology

- React 18 + Vite
- React Router + Context API
- Node.js + Express
- MongoDB + Mongoose
- JWT authentication
- Role-based authorization
- CSS/custom properties with responsive and dark-theme support

## Key Features

- Patient and therapist workflows
- Therapy session scheduling/status tracking
- Treatment plans and progress updates
- Dashboard-oriented statistics
- Role-aware workflows
- RESTful backend API
- Responsive interface
- Dark theme

## Architecture

React/Vite frontend → REST API → Express/Node backend → MongoDB/Mongoose, with authentication/RBAC middleware around protected workflows.
