# University Course Projects

## Role

Academic archive containing a broad collection of university/course projects across computer science domains.

## Purpose

This repository preserves the breadth of the university project portfolio in one place. It is an archive/collection rather than the primary showcase for every individual project.

## Domains Represented

- Systems programming
- Networking
- Databases
- Compilers
- Algorithms
- Web development
- Other academic/coursework areas

## Important Relationship

Several projects in this collection also have dedicated standalone repositories. When that happens:

- Standalone repository = primary showcase
- Collection repository = academic archive/reference

Do not duplicate improvement work simply because the same project exists in both places.

## Audit Decision

README was already sufficiently strong and generated compiler artifacts produced false-positive `TODO` search results. No broad code changes were justified.

## Portfolio Position

**High as an academic breadth archive; lower priority as an individual featured project.** The strongest standalone projects should be linked from the final profile instead of asking recruiters to inspect the entire archive.
