# Compiler Project

## Role

Compiler-design coursework repository covering frontend analysis and middle-end/intermediate representation work.

## Major Areas

- Lexical analysis
- Syntax analysis
- Semantic analysis
- AST construction
- Intermediate code generation
- Quadruple representation
- Token classification and symbol-table concepts

## Repository Structure

The repository is organized around Deliverable 1 Frontend and Deliverable 2 Middle-End work, with lexical, syntax, semantic, AST, and quadruple areas.

## Technology / Tools

- C
- Flex/Lex-style lexer tooling
- GCC
- Bison/Yacc where required by individual parser deliverables

## Documentation Work

A standalone README was added describing the deliverable structure, generated `lex.yy.c` artifacts, reproduction workflow, scope, and coursework limitations.

## Important Caution

Generated compiler artifacts and coursework-specific source were intentionally not aggressively refactored. The objective is to preserve correctness and submitted-coursework context rather than perform cosmetic refactoring.

## Collection Relationship

Also represented in the university academic collection. The standalone repository is the primary technical showcase.

## Portfolio Position

**High technical depth.** Useful evidence of compiler construction, C programming, formal language concepts, and systems-level understanding.
