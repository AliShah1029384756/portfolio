# FAST-NUCES Resource Hub

## Role

FAST-specific academic resource hub built around the user's university journey and intended to help FAST-NUCES students find scattered study material more easily.

## Purpose

Centralize semester links, course references, past papers, project examples, and useful repositories in a student-friendly interface.

## Audience

Primarily FAST-NUCES students. This is intentionally different from EduCore, which targets a broader public learning audience.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Static GitHub Pages deployment
- No backend/database required for the core site

## Features

- Semester 1–8 browsing
- Course/resource grouping
- Repository references
- Past-paper hub
- Project examples
- Search/browsing-oriented interface
- Responsive navigation
- Reveal animations

## Documentation Work

README was improved to clarify the FAST-specific purpose, student workflow, technology, deployment, curation principles, contribution guidance, scope, and distinction from EduCore.

## UI Decision

The existing frontend was not blindly redesigned. It already had a deliberate visual system and interaction layer. Further UI changes should only be made after safely inspecting the complete frontend and identifying real UX/accessibility/performance improvements.

## Portfolio Position

**High community/education-impact value.** Strong evidence of initiative and helping fellow students, but should be presented as a resource/community project rather than a generic commercial product.
