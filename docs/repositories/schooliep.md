# SchoolIEP

## Role

Full-stack education-domain application demonstrating student records, Individualized Education Plan (IEP) workflows, goals, parent coordination, and progress reporting.

## Purpose

Organize IEP-related school workflows in a structured software system while demonstrating full-stack engineering and domain-specific workflow design.

## Key Features

- IEP lifecycle management
- Student records
- Parent profiles and coordination
- Learning goal creation
- Goal/progress tracking
- Period-based progress reports
- JWT authentication
- Protected workflows
- Domain-specific REST APIs
- React dashboard

## Technology

- React + Vite + JavaScript
- Node.js + Express
- MongoDB + Mongoose
- JWT authentication

## Architecture

React/Vite frontend → REST API → Node/Express backend → MongoDB/Mongoose.

The backend is organized around authentication, students, parents, IEPs, goals/progress, and reporting. fileciteturn364file0
