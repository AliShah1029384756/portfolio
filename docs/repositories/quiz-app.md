# Quiz App

## Role

Small frontend timed-quiz application demonstrating interactive state flow, timers, scoring, and result presentation.

## Purpose

Practice managing multi-question quiz state, countdown timing, answer handling, scoring, and final performance feedback.

## Features

- Multiple-choice questions
- Timed quiz flow
- Question/state progression
- Real-time answer feedback
- Score calculation
- Final performance summary

## Technology

- HTML5
- CSS3
- Vanilla JavaScript

## Architecture

Static client-side application with quiz state and timer logic handled in JavaScript. No backend/database is required for the current experience.
