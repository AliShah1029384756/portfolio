# Calculator

## Role

Small polished frontend utility project demonstrating vanilla JavaScript interaction and arithmetic state handling.

## Purpose

Practice DOM control, event handling, calculator state, keyboard/button input, and separation between expression display and calculation logic.

## Features

- Basic arithmetic operations
- Live expression display
- Sign toggle
- Percentage control
- Clear/reset
- Keyboard-friendly interaction
- iOS-inspired polished interface
- Responsive presentation

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- GitHub Pages/live static hosting

## Audit Notes

README accurately describes the project as a lightweight frontend calculator and already documents learning outcomes and sensible future ideas such as history and unit tests. The current UI is more polished than a basic practice calculator, with a hero section, metadata cards, responsive layout, and calculator stage.

No major code rewrite is justified for its current purpose. Future improvements should focus on tested calculation logic, history, accessibility, and edge-case handling rather than visual complexity.

## Portfolio Position

**Low-medium.** Good supporting evidence of frontend fundamentals and UI polish, but not a primary portfolio project.
