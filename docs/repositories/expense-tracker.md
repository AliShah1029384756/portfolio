# Expense Tracker

## Role

Small frontend personal-finance application demonstrating state management, calculations, transaction modeling, and browser persistence.

## Purpose

Allow a user to record income and expenses, calculate totals and running balance, and review transaction history.

## Features

- Add income transactions
- Add expense transactions
- Transaction descriptions
- Amount validation
- Category selection
- Income / expense / balance summary
- Dynamic transaction history
- Persistent browser storage through `localStorage`
- Clear-all workflow
- Responsive dashboard presentation

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Browser `localStorage`
- Google Fonts

## Architecture

Static client-side application with no backend/database. Transaction state is managed in JavaScript and persisted locally.
